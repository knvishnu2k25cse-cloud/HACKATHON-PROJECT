📊 DATABASE SCHEMA
══════════════════════════════════════════════════════════════════════════

complaints
  ├── id (TEXT, PRIMARY KEY)           e.g., GRV-2025-001
  ├── source (TEXT)                    'citizen' | 'collector_order'
  ├── citizen_name (TEXT)
  ├── citizen_location (TEXT)
  ├── original_text (TEXT)             Full complaint/order text
  ├── aadhaar_hash (TEXT)              Masked Aadhaar (1234****5678)
  └── created_at (DATETIME)

issues
  ├── id (INTEGER, PRIMARY KEY AUTOINCREMENT)
  ├── complaint_id (TEXT, FOREIGN KEY) → complaints.id
  ├── department (TEXT)                One of 8 departments
  ├── issue_text (TEXT)                Specific issue for this dept
  ├── deadline (TEXT)                  Extracted deadline
  ├── priority (TEXT)                  'High' | 'Normal'
  ├── status (TEXT)                    'Pending' | 'Resolved'
  ├── resolution_note (TEXT)
  ├── resolved_at (DATETIME)
  └── created_at (DATETIME)

otp_store
  ├── aadhaar (TEXT, PRIMARY KEY)
  ├── otp (TEXT)
  ├── created_at (DATETIME)
  └── verified (INTEGER)               0 | 1


🔌 API ENDPOINTS
══════════════════════════════════════════════════════════════════════════

OTP & Authentication:
  POST   /api/otp/send                 Send OTP to Aadhaar
  POST   /api/otp/verify               Verify OTP

Complaints:
  POST   /api/complaints/submit        Submit citizen complaint
  GET    /api/status/:complaintId      Track complaint status

Collector Orders:
  POST   /api/collector/submit-text    Submit order as text
  POST   /api/collector/upload         Upload & OCR document

Dashboards:
  GET    /api/departments              List all departments + stats
  GET    /api/dashboard/department/:dept  Get issues for department
  GET    /api/dashboard/collector      Get all issues + stats
  POST   /api/issues/:id/resolve       Mark issue as resolved
