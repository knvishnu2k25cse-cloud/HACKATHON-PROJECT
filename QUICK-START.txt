📋 STEP 1: Configure OpenAI API Key (REQUIRED for AI features)
────────────────────────────────────────────────────────────────────────────
Edit:  backend/.env
Add:   OPENAI_API_KEY=sk-your-actual-openai-key-here

ℹ️  Without a valid key, the system will use keyword-based fallback
   (still functional for demo, but less accurate)


🚀 STEP 2: Start the Application
────────────────────────────────────────────────────────────────────────────
Run:   ./start.sh

OR manually in two terminals:

  Terminal 1:  cd backend && node server.js
  Terminal 2:  cd frontend && REACT_APP_API_URL=http://localhost:3001 npm start


🌐 STEP 3: Access the Application
────────────────────────────────────────────────────────────────────────────
Frontend:  http://localhost:3000
Backend:   http://localhost:3001


📝 DEMO WALKTHROUGH
────────────────────────────────────────────────────────────────────────────
1. HOME PAGE → Overview and navigation

2. FILE COMPLAINT (Citizen Flow):
   • Aadhaar: 123456789012 (any 12 digits)
   • OTP will be shown on screen (demo mode)
   • Fill complaint form → AI analyzes and routes
   • Note your Complaint ID for tracking

3. TRACK STATUS:
   • Try sample IDs: GRV-2025-001, GRV-2025-008
   • See department routing and resolution status

4. DEPARTMENT DASHBOARD:
   • Select any department (e.g., Water Supply, Health)
   • View routed issues
   • Mark issues as resolved with notes

5. COLLECTOR DASHBOARD:
   • Overview of all departments
   • High-priority alerts highlighted in red
   • Real-time stats and resolution tracking

6. COLLECTOR ORDERS:
   • Paste order text OR upload scanned image/PDF
   • OCR extracts text automatically
   • AI splits multi-department directives

🤖 AI CLASSIFICATION FEATURES
────────────────────────────────────────────────────────────────────────────
✓ Multi-department detection and auto-splitting
✓ Urgency keyword detection (flood, fire, collapse, emergency, etc.)
✓ Auto-mark High Priority if:
  • Urgency keywords found OR
  • 3+ departments involved
✓ Deadline extraction from text
✓ Department routing to 8 categories:
  - Water Supply
  - Roads & Infrastructure  
  - Electricity
  - Sanitation
  - Health
  - Education
  - Revenue/Land Records
  - General Administration


🛑 STOPPING THE APPLICATION
────────────────────────────────────────────────────────────────────────────
Press Ctrl+C in the terminal running ./start.sh

OR manually kill processes:
  pkill -f "node server.js"
  pkill -f "react-scripts"


💡 TIPS FOR DEMO
────────────────────────────────────────────────────────────────────────────
• Start with GRV-2025-008 (flood emergency) to show high-priority routing
• Submit a new complaint mentioning multiple issues to demo AI splitting
• Use Department Dashboard to show real-time resolution workflow
• Upload a text file as "scanned order" to demo OCR (faster than image)
• Show Collector Dashboard last for full system overview
